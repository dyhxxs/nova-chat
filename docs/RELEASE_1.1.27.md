本次将当前已验证的客户端与网关源码同步到公开仓库，并更新中英文介绍、产品展示图、使用指南与模型配置文档。

## 这版有什么

- **更鲜明的默认角色**：Lumi 设定为 20 岁中文专业女大二学生，有具体的课程、朋友、偏好和小习惯，气质偏孤高，熟悉后偶尔带一点腹黑。
- **更短的日常回复**：减少固定追问、长篇安慰、动机分析和道歉评分；沿当前对话上下文延续角色的不开心、开心与聊天节奏。
- **保留自定义人设**：旧默认字段在读取时精确升级，自己修改过的人格和说话方式保留，记忆与参考脸不变。
- **独立的角色照片**：上传、裁剪或替换参考照片，后续生成继续使用参考脸；照片失败可修改提问再试，旧失败描述不污染后续场景。
- **三套模型服务**：普通聊天、陪伴聊天、陪伴图片各自配置；管理员可以获取目录、搜索并选择模型，保存后生效。
- **配置只写与请求隔离**：服务商地址、Key 保存后不回显；换址必须填新密钥，防止旧 Key 被发往新服务。
- **完整聊天工具**：纳入个人资料库、文档导入、内置工具、自定义助手、回复朗读、对话分支、收藏、备份与账户安全中心。
- **暖白灰绿界面**：独立陪伴入口和角色设置，普通聊天继续保留完整模型与工具选项。

## 升级与使用

管理员可独立更新网关和客户端。部署前备份数据库、上传文件和运行配置，保持 SERVER_MASTER_KEY。原有角色资料采用保留自定义字段的升级方式；不要通过清除应用数据或重建角色来完成默认人设升级。

源码版本不等于 GitHub 上已经提供同版本的安装包。Android 安装包以 Releases 实际资产为准；本次源码同步不修改现有下载文件。iOS / Web 客户端代码包含在仓库中，iOS 原生安装与完整真机覆盖仍需验证。

角色情绪与经历由模型根据设定和上下文生成，不表示真实自主意识。照片由图片模型生成，参考脸一致性受服务商能力影响。资料问答的来源片段帮助核对答案，不保证模型理解完全正确。
