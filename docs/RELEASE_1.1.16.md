## 明确边界

1. 网关依然在本机，公网使用原有临时隧道；本机关机、网络或隧道故障都会不可用。这次没有完成云端常驻部署。
2. 天气是Open-Meteo模型天气/预报，范围1–16天；地点缺失会询问，重名地点要澄清。默认公共接口为非商业服务，商业部署需要合适的许可与服务。
3. 汇率是带日期的工作日参考价，不是交易价。日期工具不处理农历、工作日、法定节假日。
4. 免密钥搜索为Bing RSS备用入口，可能限流、不可用或返回不相关结果。模型被提示核对并换关键词；不能保证搜索质量，管理员可配置Brave Search。
5. 网页阅读只支持公开HTML/文本；不绕过登录/验证码，不执行页面代码或访问内网。内置计算器不是代码沙箱。
6. 外部工具将必要的城市、查询词、货币对或URL发送给相应服务。不会发送模型API Key，但用户仍不应把秘密放进搜索词或URL。
7. 后台请求续接依赖网关进程仍存活；重启会中断活动请求。已有账户/存储/依赖风险未因本轮工具补全而全部消失。

原有未提交的账户、备份、存储等改动均保留，不计为本轮新增能力。
