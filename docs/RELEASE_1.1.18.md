日期：2026-09-09（Asia/Shanghai）。本轮基于1.1.17继续开发；天气、时间等8项工具、既有资料库/账户/备份能力均保留，不重复算作本轮新增。

| 能力 | 实际实现 |
| --- | --- |

## 怎么使用

1. 安装本版Android预览包并登录，进入 **设置 → 数据与帮助 → 个人资料库**，或从聊天输入框“管理资料”进入。
2. 选择“导入文件”导入文字型PDF，查看导入提示，再“查看 / 编辑”核对提取正文。扫描PDF需要先OCR；加密PDF需要在有权访问的前提下另存未加密版本。
3. 新建笔记或编辑资料时，内容会先写入当前设备草稿。只有出现“草稿已保存到本设备”才表示该版本已落盘；“保存资料”才更新网关资料库和检索索引。
4. “收起编辑（保留草稿）”回到资料列表，或离开页面后再回来，可以继续编辑。同一账户已有草稿时，打开其他资料不会覆盖它；先保存或明确放弃。
5. 保存到网关遇到版本冲突/原文被删，可导出文字或“另存为新资料”，不会强行覆盖另一设备的修改。
6. 可以先“检索原文（不调用模型）”，再开启“资料问答”提问。相关片段会发给配置的模型服务，不是离线问答；开关重启后默认关闭。

## 边界与未完成

- ADB无连接设备，没有声称真机安装、键盘/大字号/返回手势、原生文件选择器或iOS体验验收通过；Web export也不等于浏览器视觉验收。
- 仍使用原有临时公网隧道，本机网关已重启到本版；电脑/隧道关闭就会离线。没有新建隧道、常驻云部署、GitHub发布、commit/push或改生产模型配置。
- PDF解析是文字层提取，不是OCR或排版还原；即便页面有文字，也可能遗漏图像、表单、隐藏文字或多栏表格顺序。Worker不是OS安全沙箱，V8限额不是全进程内存上限。
- 草稿仅本设备、按账户一份、明文保存，不跨设备同步；立即强杀/存储不足/卸载仍可能丢失未落盘内容。资料正文/原文件/聊天来源的既有保留规则不变，删除资料不删除原上传附件或已有来源快照。
- 检索仍为中文词法而非embedding，不能保证同义词、泛泛追问、全文总结召回。本轮未加入语音、提醒、OCR、向量检索或任意电脑操作；不宣称已全面超过成熟产品。
