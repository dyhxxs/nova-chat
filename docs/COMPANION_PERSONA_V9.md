# 人设与独立话题：陪伴 v9

AI 陪伴现在从人设进入各自的对话列表。同一人设可以分别聊电影、日常或工作，每条对话独立保存消息、草稿和标题。点击人设只打开列表，点击“新对话”才生成空白聊天；打开已有对话不会新建另一条记录。

## 人物与聊天分别保存

- 人设层：名字、对用户的称呼、完整提示词、外貌、参考脸与用户主动保存的长期记忆。
- 对话层：消息、情绪和场景的历史、附件、草稿、标题、置顶与归档状态。
- 模型请求只使用当前对话历史和已启用的长期记忆。其他话题的内容不会自动进入当前聊天。

已有陪伴聊天继续使用原 companionId，直接归入原人物。更改人设名字只更改人物称呼，不改写话题标题。人设列表与话题列表通过独立路由进入，打开聊天返回原 Chat 实例，避免重复页面触发请求恢复。

## 完整人设提示词

新增 personaPrompt 字段，最多 12000 字符，可直接粘贴背景、性格、说话方式、情绪节奏和多轮示范。完整提示存在时，角色按照该提示扮演，旧的简要性格与说话方式不会混入。清空提示后使用简要设定。示范用于学习口吻，不被当成实际共同经历。

沈知意采用提供的完整提示词，包含大小姐背景、嘴硬心软、炸毛与缓和等设定。账号首次读取人设列表时安装一次，用户后续编辑或删除不会被模板覆盖。

Lumi 保留20岁中文系学生、慢热、有点孤高和偶尔腹黑的特点。新版补充具体生活和口语、多种回复长度、从生气到缓和的连续对话，以及认真难过和普通分享的不同反应。减少重复追问、客服式安慰、动机分析和自动建议。可编辑的完整人物提示见 [COMPANION_DEFAULT_PERSONA_V9.txt](COMPANION_DEFAULT_PERSONA_V9.txt)。

安全、身份真实性和实际工具结果由运行时规则管理；自定义人物仍保留自己的口吻和示例。用户直接询问真人身份或照片真实性时会如实回答。

## 升级与兼容

数据库增量创建完整提示词表与模板安装记录。旧默认按精确文本识别升级，自定义人物资料保留。省略 personaPrompt 的局部更新不会清空已有提示。

角色资料通过 x-nova-companion-profile-version 协商：v3 返回完整提示和外貌，v2 返回外貌，v1 返回原字段，保持旧 strict 客户端可用。新功能需要同时更新客户端与网关；仅安装新客户端不能让旧网关获得完整人设能力。
