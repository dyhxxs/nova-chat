# 手机聊天与人物判断：陪伴 v10

用户反馈 v9 仍输出“（刚睡醒那种语气）”、心理旁白，并把状态、解释和追问拼在一条回复里。v10 将所有人物的实际回复统一为手机文字消息；人设里的动作和内心示范只帮助理解性格，不作为输出格式。默认 Lumi 增加自己的喜好、判断与情绪，不把每条消息都变成帮助、安慰、心理分析或迎合。

## 当前行为

- 普通短问候默认只回一小句，例如“改稿。”或“有事？”，不自动接解释和反问。
- 人物通过说什么、用什么词、是否愿意继续聊来体现性格，不用括号动作、语气标签、心理独白或旁白表演。
- 一个回复表达一个当下态度。拒绝、道歉、告别不再自动补第二轮追问、关心或嘴硬找补。
- 保留各自的偏好，被追问时再解释；认真说事或自己确实感兴趣时可以多说，所有人物不会被统一成冷淡短句。
- 完整人设与简要设定两种分支都附加手机消息规则，末尾规则保留预算，12000 字符的人设及记忆不会挤掉它。

沈知意继续使用 人设提示词.txt 全文，没有改写用户提供的性格和多轮示例。运行时输出规则优先于其中括号动作的示范。Lumi 的可编辑全文位于 [COMPANION_DEFAULT_PERSONA_V10.txt](COMPANION_DEFAULT_PERSONA_V10.txt)。
