# Nova Chat 1.1.17 — 个人资料库与可追溯资料问答

日期：2026-09-09（Asia/Shanghai）

## 本轮新增

这次在1.1.16的天气、时间等8项工具基础上，新增完整的个人资料流程，而不是重复把上一轮成果计入本轮。

| 能力 | 实际实现 |
| --- | --- |
| 个人资料库 | 独立账户保存笔记，查看、编辑、删除；100份/200万字符，每份12万字符 |
| 文件导入 | TXT、Markdown、JSON、CSV、DOCX、XLSX、PPTX、ODT、EPUB等现有可提取文字格式 |
| 原文检索 | 中文双字词、英文/数字关键词，本地SQLite索引检索，不调用模型 |
| 资料问答 | 显式开启后检索相关片段，使用现有模型回答；无命中不调用模型并明确说明 |
| 来源快照 | 回答支持[资料N]引用，可展开网关提供的标题、片段号、更新时间与原文 |
| 编辑与删除保护 | 同账户正文去重、容量限制、编辑版本冲突、删除二次确认 |
| 端到端适配 | Responses/Chat Completions，REST/WS/后台任务快照/本地聊天存储 |
| 隐私与工具保护 | 账户隔离、共享令牌拒绝、资料模式禁用外部工具，异步账户切换保护 |

### 使用方法

1. 安装1.1.17预览包，登录已有账户。
2. 打开 **设置 → 数据与帮助 → 个人资料库**，或聊天输入框的 **管理资料**。
3. 新建笔记或导入文件，查看提取后的正文，确认没有丢失需要的表格信息。
4. 可以先“检索原文（不调用模型）”；再“新建资料问答”，或在聊天开启“资料问答”。新建资料问答只填入草稿，不会自动发送。
5. 用资料里的具体名称或关键词提问，展开答案下的“查看资料来源”，核对[资料N]与证据。

资料模式重启/恢复登录后需重新开启。编辑正文需要手动保存；关闭编辑有放弃确认，但系统返回/页面销毁不保证保留未保存的草稿，请先保存。单份资料可在编辑区导出Markdown。

## 重要边界

1. **不是完整语义知识库**：采用关键词检索，最多6片段、每文档3片段；同义词、单字中文、泛泛追问、全文总结不保证召回，不能承诺读完全部资料或完全消除幻觉。
2. **资料库不支持PDF/OCR**：扫描件、图片、旧二进制Office、MOBI暂不支持；普通聊天可上传某格式不代表资料库可以提取它。表格/排版可能丢失，导入后需要核对。
3. **不是离线/端到端加密**：相关片段发给管理员配置的模型服务；网关正文与索引、本机聊天来源快照均为明文。服务器运营方仍具有数据库和文件系统权限。
4. 资料模式由网关强制关闭内置工具、上游搜索、上游代码和图片生成。资料作为不可信数据而非系统指令；这不是对提示注入绝对免疫的保证。
5. 删除资料仅影响该条目与索引，不清理原上传附件、既有答案/来源、进行中请求或外部备份。重复/失败导入也可能留下原上传附件；逻辑删除不是安全擦除。
6. 标准聊天备份排除来源快照与资料ID，但回答正文仍可能包含资料内容且不自动脱敏。恢复副本可能含来源；单独导出的资料Markdown包含正文。
7. 关闭资料模式不移除聊天历史中已生成答案，之后再启用外部工具时仍须注意历史中的秘密。来源显示的是提供给模型的片段，不证明每个片段都被使用或引用正确。
8. 网关仍在本机，公网是原临时隧道；关机/断网/隧道失效会不可用。任务只保留在网关进程中，重启会中断活动请求。**未完成云端常驻部署**。
9. 本轮没有增加依赖或进行新一轮依赖审计；历史记录中的6项moderate依赖风险未在本轮关闭。真机验收、语音交互、提醒任务、PDF/OCR、向量检索等仍需独立实现和验证，不能宣称已经全面超过任何成熟产品。
