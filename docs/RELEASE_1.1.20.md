# Nova Chat 1.1.20 — 对话分支与提问改写（本地候选）

日期：2026-09-09（Asia/Shanghai）。源码与workspace版本1.1.20，Android versionCode 22、iOS buildNumber元数据22。**未发布1.1.20公网包，未通过公网聊天发布门禁。**

## 新增功能

- 完成的助手回复下点击“创建分支”，确认后复制截至该回复的已完成消息，切换到独立新会话；后续消息不复制。
- 已发送、无附件的纯文字问题下点击“改写提问”，仅复制问题之前的已完成消息，把完整原问题放入新分支输入框；用户修改后自行发送，旧回答及其后续消息不复制。
- 原对话、原草稿、置顶、归档和备份来源不变。新会话及消息使用新ID；不继承旧任务ID、生成控制、usage、错误或重试状态，避免恢复旧生成任务或重复统计。
- 固定自定义助手指令、原模型标签及资料来源快照保留；附件仅复制已存在的引用，不重新上传或复制服务器文件。新分支不自动改模型或工具设置。
- 有确认页、复制数量/跳过片段数量和隐私说明。创建本身不调用模型、不自动发送；附件展示仍可能访问网关，不承诺所有显示路径离线。

## 保护与边界

- 仅支持不超过10,000 UTF-16字符的纯文字提问改写，超限拒绝而非截断。来源前缀最多500条记录，已复制内容JSON预算2,000,000 UTF-16字符；本地会话达到5000时拒绝新增分支。附件数量/URI及资料来源数量另有限制。
- 来源任意一条仍在生成时拒绝分支；失败和取消片段不复制，并在确认页明确计数。当前对话有待发送附件或上传未结束时阻止创建。
- 确认绑定临时账户/Session/网关/活动会话及不可变来源对象；账户、Session、网关、会话、原文、草稿、删除或重新生成变化使旧确认失效。导航离开、后台和卸载取消确认；旧Modal或双击不能创建另一分支。
- 使用既有账户+网关快照持久化，原生SQLite/Web写队列不新增schema。读取保护状态拒绝创建；保存失败保留内存副本并显示既有数据错误，可重试，不宣称已经落盘。
- 这是明文本地副本，不是外部备份、脱敏或完整上下文保证。后续主动发送可能将历史交给网关和模型，仍受既有上下文预算限制。附件文件失效后引用也可能失效，资料来源快照不重新检索。
