# Nova Chat 1.1.15 朋友体验版

日期：2026-09-09（北京时间）。这是可直接注册使用的正常应用体验包，不是之前的 1.1.14 R3 独立 QA 包。

## 给朋友的使用方法

1. 在安卓手机浏览器打开管理员提供的完整下载直链，下载并安装 APK。
2. 打开 **Nova Chat**，登录页会显示 **版本 1.1.15**。
3. 点击“注册”，填写邮箱、至少 8 位密码和确认密码；注册完成后直接进入应用。
4. 无需输入服务器地址、API Key 或模型配置。模型由管理员配置和发布。

不要卸载旧版来“解决升级问题”，以免丢失本机聊天记录。旧正常朋友版与本版使用相同包名和签名，Android versionCode 从 16 提升为 17；实际覆盖安装尚未进行真机验证。Nova QA / QA R2 / QA R3 是独立应用，数据不会自动转入本版，可使用它们的数据备份功能手动迁移。
