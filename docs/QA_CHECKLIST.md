# 发布前人工验收清单

> 这是可复用的发布验收模板，勾选状态不代表某一版本已经完成全部人工项目。1.1.27 已完成自动化检查、Expo 导出及 MuMu 关键流程验证，iOS 原生安装与完整真机覆盖仍需继续验证。故障注入使用隔离账户、测试网关与 mock provider；真实上游调用按测试环境的既有授权与预算执行。

## 1. 安装与基础布局

- [ ] 新装测试使用独立包与隔离数据；升级测试使用相同 applicationId、相同签名和递增 versionCode，验证旧记录与设置保留。
- [ ] 首次启动、注册/登录、退出重登、手动填写网关地址均正常。不要将手机上的 127.0.0.1 当作开发电脑。
- [ ] 深/浅色、窄屏、横屏、大字体下，设置、账户安全、备份、助手库页面文字和按钮可见；长菜单可滚动。
- [ ] 键盘打开时可编辑/发送/关闭，底部不被遮挡；屏幕阅读器能读到主要按钮及状态提示。
- [ ] Android 系统分享与文件选择器可正常打开，取消不会错误显示“已备份完成”。
- [ ] Android 真机（含 16 KB 页大小环境）启动和基本操作通过。静态对齐检查不等于该项通过。
- [ ] iOS 独立构建、安装与系统文件分享通过（1.1.27 已完成 iOS Expo bundle 导出，原生安装仍待验证）。

## 2. 账户/网关隔离与草稿

- [ ] 账户 A 的历史、系统指令、自定义助手和草稿不会出现在账户 B 中。
- [ ] 同一用户 ID 在两个独立网关之间不共享历史/草稿/助手。
- [ ] 更换网关后旧令牌被清空，重新登录才能读取新网关账户。
- [ ] 两个对话输入不同草稿，来回切换、退出重登、进后台再恢复仍能看到对应文字。
- [ ] 发送旧草稿过程中输入新文字，新文字不被旧发送完成动作清空。
- [ ] 待上传附件不作为持久化草稿保存；重启后需重新选择，界面没有虚假的已上传附件。
- [ ] mock provider 输出期间切换对话不会串写；后台恢复不会重复开始模型任务。

## 3. 助手库

- [ ] 四个内置模板可预览、复制、开始新对话；开场文字只填草稿，不自动发送。
- [ ] 创建/编辑/删除自定义模板符合长度限制、空内容校验和删除确认。
- [ ] 已建助手对话固定使用创建时指令；编辑/删除模板不会改变该对话，普通对话仍使用全局指令。
- [ ] 导出标准 JSON/Markdown 后，草稿和助手指令未作为配置字段泄露。

## 4. 历史、备份与恢复

- [ ] 改名、置顶、归档与恢复；生成中不能归档；归档对话发消息会重新激活。
- [ ] 最近/置顶/归档/全部筛选正确，标题/正文/模型/附件名的中英文多关键词匹配正确。
- [ ] 系统实际保存全量 JSON，并可在空测试账户导入；确认面板数量正确，原有历史未覆盖。
- [ ] 同一文件二次导入只跳过重复来源，不重复创建；损坏/版本错误/超限文件导入前报错。
- [ ] 单对话 Markdown 可读；附件仅含名称/元数据，不含原文件 ID、URI 或二进制。
- [ ] 导入包含 streaming 消息的备份后，不自动启动任何后台请求。
- [ ] 选择文件期间换账号，旧备份不能误导入新账号。
- [ ] 仅在隔离构建模拟本地写入失败：出现可见提示，重试后恢复，内存历史不丢。
- [ ] 仅在隔离存储注入损坏记录：可恢复有效消息，原始字符串保留，恢复副本可导出。
- [ ] 读取失败/未知版本/归属错误不会用空白历史覆盖原始数据；已有恢复副本不被不同内容替换。

## 5. 安全与连接

- [ ] 两台测试设备登录后列表均可见；设备 ID 明确标注为客户端自报，不被当作可信设备名称。
- [ ] 撤销其他设备后，当前设备保留；另一设备旧 REST/WS 认证失败，界面给出重新登录提示。
- [ ] 改密错误旧密码被拒绝；相同新旧密码被拒绝；限流有明确说明。
- [ ] 改密成功所有设备重新登录；旧密码不能再登录，新密码可以。
- [ ] 用户禁用、会话到期、管理员降权后，旧连接不能继续行使失效权限。
- [ ] 单纯网络断开不会取消仍有效的 durable 任务；主动注销确实取消失效会话任务。
- [ ] 未登录诊断仅请求 health；HTTP 警告、错误域名、HTML 代理页、401、超时和取消均有清晰反馈。
- [ ] 诊断完成/取消后无遗留 socket，不出现生成调用；复制报告不含地址、令牌、账户资料或聊天。
- [ ] 新客户端连接旧网关时，账户安全 404 显示升级提示，不把失败当作成功。

## 6. 发布门槛

- [ ] 执行 npm run verify 与 npm run build，保存完整日志。
- [ ] 重新检查依赖审计并评估当前未解决项；不以破坏性强制降级掩盖审计结果。
- [ ] 生产包使用正式签名、正式包名与递增 versionCode；ALLOW_CLEARTEXT=false，只连可信 HTTPS/WSS。
- [ ] 不携带测试账号、测试数据库、.env、真实 Token/Key；确认发布下载哈希与最终 APK 一致。
- [ ] 网关升级前完成数据卷与主密钥备份，并演练回滚；记录本次部署及覆盖安装的实际结果。

出现问题时记录具体步骤、预期/实际结果、平台版本、脱敏诊断报告；不要在 issue 中粘贴令牌、密钥、明文恢复快照或私人聊天。


## 7. 存储与凭据迁移

- [ ] 记录升级前后的包名、签名和版本；迁移验收使用同包覆盖安装，不把独立新装作为通过依据。
- [ ] 为旧版和新版建立相同的**一次性测试 applicationId**，在旧版写入超过 2 MiB 单行 / 6 MiB 总量附近的可读历史后升级；确认迁移原文、活动历史与模板一致。不可使用生产账户做此实验。
- [ ] Android/iOS 真机上断电/强制关闭模拟覆盖迁移前、SQLite 提交后/marker 前、正常写入期间等窗口；失败时可见提示且不静默覆盖。
- [ ] 原始行已经无法读取时，明确显示保护提示，不误报“全部迁移成功”；没有自动要求卸载应用。
- [ ] 数据页正确显示 SQLite（原生）/AsyncStorage（Web）；迁移档案可导出且被标明敏感、不可直接导入。
- [ ] 系统安全存储不可用、读/写/删失败时，全局警告和重试可达；退出后登录页保留清理失败提示。
- [ ] 慢登录立即退出、连续换账号和网关、保存期间重启，不恢复失效旧会话、不把凭据发往旧 bootstrap 地址。
- [ ] 退出双重保护都失败时提示重启可能恢复旧登录；不显示“退出已可靠保存”的虚假状态。
- [ ] 独立助手 JSON 可通过系统分享/选择器实际保存/导入，名称、指令、开场草稿预览可滚动，截断有明确说明。
- [ ] 未确认模板来源时不能导入；导入失败文件不部分修改，重导入不覆盖本地编辑；100 个模板上限在确认时重验。
- [ ] 助手备份与对话备份不能混用；聊天备份仍不含助手私有指令或对话草稿。
- [ ] 清空对话的确认文案说明助手/恢复/迁移档案/外部备份不会一并删除；未把清空描述为安全擦除。
- [ ] 生产发布前确认新原生依赖已编入正式壳；评审 [迁移/回滚说明](STORAGE_MIGRATION.md)，不直接降级旧客户端。

## 8. 档案清理、导出与性能

- [ ] 清理与故障测试使用一次性数据，验证范围绑定当前账户与网关。
- [ ] 在一次性数据下检查四类 UTF-8 正文统计；旧恢复副本迁移后计入，不误标成磁盘占用或附件大小。
- [ ] 无外部备份勾选不能清理；预览期间换账号/网关、恢复档案变化、重复点击、读取阻止或本地保存失败均拒绝旧清理。
- [ ] 清理后当前聊天/助手/草稿及另一账号保持不变，三类档案统计归零；强制关闭再启动仍如此，新损坏记录仍能保留恢复副本。
- [ ] 仅在隔离设备注入清理写/提交失败，确认全部档案回滚；不对生产存储做故障实验。
- [ ] 系统分享选择器打开前换账号/离开页面取消旧导出；已开始分享的外部接收方能够在宽限期实际读取文件。
- [ ] 导入内存成功但模拟落盘失败时明确提示不要关闭应用，重试能保存，旧账号错误不覆盖新账号提示。
- [ ] 500 / 2000 合成会话和大正文在目标 Android/iOS 设备上测量冷启动、输入延迟、峰值内存及滚动；缓存超预算仍有正确结果，预览短但正文完整。
- [ ] Web 明确只读统计/不清理；下载成功、浏览器阻止下载、取消选择器均有合理反馈且不上传任何文件。
- [ ] 大字体/小屏/横屏及 VoiceOver/TalkBack 下，统计、风险提示、备份勾选及危险确认可读可操作，无被底部遮挡的按钮。

开发者可以先运行 `npm run benchmark:mobile -- --output .run/mobile-performance.json` 重跑纯合成基准；它不是以上人工项目的替代。
