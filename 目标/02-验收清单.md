## F. 安全和权限

- [x] API Key 不会返回给普通用户。
- [x] API Key 不会出现在移动端代码中。
- [x] API Key 不会出现在日志中。
- [x] Session Token 不会明文写入数据库。
- [x] 密码不会明文保存。
- [x] 用户资料按用户 ID 隔离。
- [x] 附件下载会验证所有者。
- [x] 用户被禁用后旧 Session 失效。
- [x] Session 撤销后旧 WebSocket 失效。
- [x] 登录、密码修改和模型请求受到限流。
- [x] 文件大小和文件类型受到限制。
- [x] 上游错误不会泄露私有信息。
- [x] 生产配置缺少主密钥时会拒绝启动。
- [x] JSON 错误响应会返回与 `X-Request-ID` 一致的 `requestId`。
- [x] 收到关闭信号后会先摘除就绪状态，再拒绝新业务请求并清理运行中任务。
- [x] 管理员可以分页查看不包含密钥和正文的审计日志。
